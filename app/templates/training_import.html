Bulk Training Import

Upload file CSV berisi daftar clip video beserta skor performanya. Setiap baris akan diproses sebagai training_ingest job di background — video di-download/di-analisis lalu dijadikan data training untuk model scoring.

⬇ Download Template CSV
Format CSV

2 kolom wajib: source dan actual_score.
Baris header boleh ada atau tidak — sistem otomatis detect.

Kolom Isi Contoh
source Path file lokal atau URL video (YouTube, TikTok, dll) C:\clips\video1.mp4
https://youtu.be/abc123
actual_score Skor performa nyata 0–10 berdasarkan views/likes/engagement 8.5 → viral
4.0 → biasa
1.0 → flop

Contoh isi file CSV:

source,actual_score
C:\Users\Anda\Videos\gaming_highlight.mp4,9.2
C:\Users\Anda\Videos\reaction_clip.mp4,6.5
https://youtu.be/xxxxxxxxxxx,8.0
https://www.tiktok.com/@user/video/123,7.5
💡 Tips: Skor 8–10 = konten yang sangat viral/bagus. Skor 4–7 = performa sedang. Skor 0–3 = konten yang tidak perform. Semakin banyak data, semakin akurat model scoring-nya.
Format: .csv — maks beberapa ratus baris per upload.
